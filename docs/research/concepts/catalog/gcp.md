# Google Cloud: concept catalog

Stage 1 research for the Google Cloud area. One row per concept, one animated diagram per row later.

## Scope

**In:** what is specific to Google Cloud and needs its own explanation. That covers how Google Cloud
organises things (resource hierarchy, projects, billing accounts, org policies), how it implements
general ideas differently (a global VPC with regional subnets, one anycast IP for a global load
balancer, live migration, Cloud Run concurrency, Spanner TrueTime), its own vocabulary (forwarding
rule, backend service, service agent, metrics scope, Log Router), and the "which Google Cloud
service do I use" comparisons (load balancers, compute, storage, databases, data processing,
orchestration, Pub/Sub vs Cloud Tasks, hybrid connectivity, ways to serve models).

**Left to other areas:** the general idea behind each product. Load balancing, DNS, BGP, NAT,
private endpoints and CDNs are in `networking.md`; RBAC, OIDC federation, envelope encryption,
WAFs, DLP and zero trust in `security.md`; Kubernetes objects, HPA/VPA, Ingress/Gateway and
network policies in `containers.md`; consistency models, replication, partitioning, columnar
warehouses and data governance in `data.md`; pub/sub, delivery guarantees, DLQs and stream
windows/watermarks in `messaging.md`; CI/CD, release strategies and IaC in `delivery.md`; SLOs,
golden signals and the three pillars in `observability.md`; backup and DR patterns in
`reliability.md`; RAG, vector search, agents and GPU capacity in `ai.md`; regions, service models,
CapEx/OpEx and migration strategies (the "6 Rs") in `fundamentals.md`. A Google Cloud row here says
how Google Cloud does it and links back through **Overlaps**.
